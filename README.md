# Westward — A Trail Journal

A small, self-contained Oregon Trail inspired game set on an original telling of the 1848 overland journey from Independence, Missouri, to Oregon City.

## Play

Open `index.html` in a modern browser. There is no build step or package install. An internet connection lets the page load its display fonts; system font fallbacks are included.

Choose a party leader, party size, trade, and departure month, then outfit the wagon and begin. Each trip is shaped by travel pace, food rations, hunting, rest, trading posts, river crossings, weather, and chance encounters. A journey saves automatically in the same browser. Use **Save journey** to keep a checkpoint, and **Continue saved trip** to resume it.

## Files

- `index.html` contains the setup, journey dashboard, and ending screens.
- `styles.css` defines the responsive journal-inspired visual design.
- `game.js` holds the route, supplies, journey state, encounters, and local save behavior.

The artwork and writing are original. Historic stop names are used as landmarks; distances and events are simplified for play.
